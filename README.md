# Desafios-FrontEnd
Este repositório reúne uma coleção de pequenos projetos e desafios de interface providos pelo site [Frontend Mentor](https://www.frontendmentor.io/challenges/), desenvolvidos para aprimorar minhas habilidades em HTML5, CSS3 e JavaScript.

## Projetos Concluídos

**03. Social Links Profile** | Iniciante | HTML5, CSS3 (Flexbox) | [Deploy](https://vinicius-duarte837.github.io/Desafios-FrontEnd/03-social-links-profile/)

## Objetivos de Aprendizado

- Prática contínua de técnicas modernas de CSS3 (**Flexbox e Grid Layout**)
- Prática contínua de layout responsivo (**Mobile-First**)
- Aplicação de boas práticas de **HTML Semântico** e **Acessibilidade Web**
