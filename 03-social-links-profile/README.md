### What I learned

This one was easier than the previous challenge, since all the components were stacked vertically, I just needed to use flex direction to align everything nicely, the rest was just using personal judgement on the margins and paddings. One thing I had to look it up was the "transform: scale()" property, so the main div and its components would scale down automatically on smaller screens, I was anaware that this property existed.

```css
.main{
        transform: scale(0.8);
    }
```
